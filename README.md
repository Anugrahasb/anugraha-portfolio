# Anugraha S.B. — Interactive Developer Portfolio

A responsive portfolio for an Android Developer and Kotlin Multiplatform Engineer.

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a browser. No build step or dependencies are required.
3. Keep `style.css`, `script.js`, and `Anugraha-SB-Resume.pdf` beside `index.html`.

For a local web server, run `python3 -m http.server 8000` in this folder and visit `http://localhost:8000`.

## Publish with GitHub Pages
1. Create a repository named `Anugrahasb.github.io` for a user site, or any repository name for a project site.
2. Upload the contents of this folder to the repository root (not the enclosing folder itself).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/(root)`, then save.
5. Wait for the deployment and open the URL shown in Pages settings.

## Main files
- `index.html`: profile, work history, projects, skills and contact links.
- `style.css`: responsive visual design and interactions.
- `script.js`: profile badge flip and scroll companion behavior.
- `Anugraha-SB-Resume.pdf`: résumé download linked from the page.

## Sections and interactions
- Hero and downloadable résumé
- About and focus areas
- Selected projects with illustrative UI concepts
- Work experience timeline
- Technical toolkit and learning focus
- Contact links
- Click-to-flip profile badge and scroll companion

The structure follows the reference portfolio's broad section pattern (profile, featured work, experience, skills/toolkit, contact) while using original styling and Anugraha's own career details. It does not copy the reference repository's source code or assets. The typography uses Space Grotesk and IBM Plex Mono from Google Fonts; an internet connection is required for those web fonts to load.
